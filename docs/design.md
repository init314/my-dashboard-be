# SENTIS 대시보드 디자인

전체 셸, 홈, 앱 패널, 입력 컨트롤, 앱 독과 로그인은 어두운 네이비 배경·청록색 네온·가는 HUD 테두리로 통일한다. 홈은 COMMAND CENTER와 SENTIS 코어, 실제 연결 상태, 사용량 패널, 대화, 오늘 일정, 기존 앱/위젯 배치를 제공한다. 장식 코어의 회전은 실제 작업량을 의미하지 않는다. 대화·일정·앱 실행 동작은 기존 모듈이 담당한다.

색상은 `design-system.css`의 semantic token으로만 정의하고 `sentis-hud.css`와 `codex-usage.css`는 토큰을 참조한다. 밝은 테마도 동일 구조와 읽기 대비를 유지한다. Tailwind 진입점 `tools/ui/workspace.css`에서 번들로 생성한다. `npm run build`를 tools/ui에서 실행한다.

## 홈 사용량

- Codex 계정이 제공하는 각 한도의 사용 비율은 청록색 게이지이며 75% 이상은 경고색, 90% 이상은 위험색이다.
- 5시간·주간 한도 등 창 길이는 upstream 데이터에 따른다. 초기화까지 남은 시간과 잔여 시간 비율은 황금색 게이지다. 표시 시간에 마우스를 올리면 현지 초기화 예정 시각을 확인한다.
- 현재 대화 컨텍스트는 별도 게이지다. 새 세션이나 데이터 미제공은 0%로 표시하지 않는다. 정확한 토큰 정보는 usage 이벤트를 기다린다.
- 주기 조회는 대화 실행 중에는 건너뛰고, 서버 rateLimits 이벤트는 즉시 반영한다. 조회 지연·로그인 필요·한도 미제공은 각각 명시한다. 유료 모델 호출 없이 account API만 조회한다.
- 전체 화면 전환은 같은 DOM과 대화/사용량 상태를 유지한다. 휴대폰은 한도 2열과 컨텍스트 요약으로 줄이고, 작은 전체 화면에서는 패널 내부 스크롤을 허용한다.

접근성: 게이지마다 한국어 이름과 aria-valuenow/valuetext를 제공하고 미제공 상태에서는 숫자를 생략한다. 초 단위 카운트다운을 live region으로 반복 낭독하지 않는다. prefers-reduced-motion에서는 코어 회전과 게이지 전환을 중단한다. 테마 대비, 반응형, 실제 브라우저 화면과 사용량 상태 테스트를 통해 검증한다.
